# 모델 A 평가 결과: 강사님 4질문 기준 (2026-09-29)

대상: Gemma 4 E4B QLoRA (서비스 이름 `itda-gemma4-e4b-q4_k_m`, 평가 때 등록 이름 `itda-gemma4-e4b:q4_k_m`) vs 베이스 (`gemma4:e4b-it-q4_K_M`)
공통 조건: Ollama, Q4_K_M, temperature 0, 생각 모드 끔(`think: false`), 합성 평가 세트(synth_eval 300건, 학습 미사용)

## 1. 학습은 안정적인가 (W&B)
- 학습 기록(trainer_state.json)을 W&B 프로젝트 itda-model-a에 옮겨 확인 (`ml/train/log_to_wandb.py`)
- train/loss 0.129 → 0.005, eval/loss 0.0163 → 0.0119 (100스텝 간격 5회, 최저점 = 마지막 스텝 496)
- grad_norm 최대 0.34, 중앙값 0.07, NaN 0건, 기울기 자르기 기준(1.0)에 닿은 적 없음
- learning_rate: warmup 10스텝 후 선형 감소, 설정대로 동작
- 판단: 과적합·불안정 징후 없음. 2에폭 이후 train이 eval보다 낮아지므로 2에폭에서 멈춘 것이 적절

## 4. 사람이 보아도 좋은가
### LLM Judge (gpt-5-mini, reasoning low, 블라인드 쌍대 비교, 순서 교차 2회)
- 메모 50건: 두 답이 다른 메모 40 + 같은 메모 10 (참고 정답 함께 제공)
- 승패: QLoRA 78%, 베이스 6%, 무승부 16% (순서 바꿔 판정이 달라진 메모 2건)
- 기준 평균(1~5): 정확성 4.24→4.91, 완전성 4.09→4.90, 규칙 준수 4.57→4.84, 필드 정확성 3.57→4.88, 근거 충실도 4.39→4.87, 평균 4.17→4.88
- 오류 코드(50건 합): 필드 오류 41→5.5, 사건 누락 16.5→1.0, 유형 혼동 5→0, 목록 밖 관찰 2.5→2.0(가장 덜 개선)
### 사람 블라인드 평가 (팀원 4명 × 20건, 두 답이 다른 메모)
- 선택: QLoRA 60(75%), 베이스 10(12.5%), 비슷함 10(12.5%). 비슷함 제외 부호 검정 p < 0.001
- 메모별 다수결: QLoRA 17, 비슷함 2, 베이스 1. 만장일치 QLoRA 7건
- LLM Judge와 같은 판단 71%(57/80), 다수결과 Judge 일치 15/20
- 평가자 간 Fleiss' κ 0.08 (선택이 한쪽으로 몰린 데 따른 κ 역설, 두 평가자 일치 비율 63%)
- 평가자 의견: QLoRA가 반복 질문을 식사량 감소로 추출, "다 드심"의 없었음 판별 누락 → 목록 밖 관찰·없었음 판별이 남은 약점

## 최종 판단
본 QLoRA 모델은 학습이 안정적이었고, 같은 조건에서 베이스 대비 F1 0.857→0.986, 메모 완전일치 65%→95%로 향상되었다. 일반 능력 하락은 1.2%p로 허용 기준 이내였고, LLM Judge(78% 승)와 사람 블라인드 평가(75% 선호) 모두 QLoRA를 선호했다.

## 한계와 다음 과제
